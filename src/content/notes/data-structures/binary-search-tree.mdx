二叉搜索树的每个节点都维护同一个不变量：左子树中的值小于当前节点，右子树中的值大于当前节点。查找、插入与删除，都围绕维护这条规则展开。

## 节点定义

```ts title="binary-search-tree.ts"
class TreeNode {
  value: number;
  left: TreeNode | null = null;
  right: TreeNode | null = null;

  constructor(value: number) {
    this.value = value;
  }
}
```

## 插入操作

从根节点开始比较：更小就走左边，更大就走右边，直到遇到空位置。

```ts title="insert.ts"
function insert(root: TreeNode | null, value: number): TreeNode {
  if (root === null) return new TreeNode(value);

  if (value < root.value) {
    root.left = insert(root.left, value);
  } else if (value > root.value) {
    root.right = insert(root.right, value);
  }

  return root;
}
```

这段代码的递归含义是：**把问题交给正确的子树，并接回更新后的子树根节点。**

## 查找复杂度

若树的高度为 $h$，查找时间复杂度为

$$
T(h)=O(h).
$$

平衡情况下 $h\approx\log_2 n$，所以查找接近 $O(\log n)$；最坏情况下树退化成链表，$h=n$，复杂度变为 $O(n)$。

## Python 版本

```python title="search.py"
def search(node, target):
    while node is not None:
        if target == node.value:
            return node
        node = node.left if target < node.value else node.right
    return None
```

递归更接近定义，迭代通常避免了调用栈开销。选择哪一种，应由可读性和实际约束决定。
