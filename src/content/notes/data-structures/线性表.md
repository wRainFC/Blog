## 2.1 线性表

线性表是由 $n\;(n\ge 0)$ 个表项组成的有限序列：

$$
L=(a_1,a_2,\ldots,a_n).
$$

其中，$a_i$ 是表项，$n$ 是表长；$n=0$ 时称为空表。$a_1$ 是表头，$a_n$ 是表尾。除表头和表尾外，每个表项分别有唯一的直接前驱和直接后继，因此线性表中的逻辑关系是一对一的。

线性表通常要求所有表项具有相同的数据类型，并可分为有序表和无序表。

### 线性表的存储方式

- **顺序存储**：用相邻的物理位置表示逻辑上的相邻关系，得到顺序表；
- **链式存储**：在结点中保存指向后继或前驱的指针，得到链表。

> [!info]- 如何在一个顺序表中保存异构数据
>
> 用带类型标记的联合体：如果确实需要在同一表中保存整数、字符、浮点数或指针，可以为每个表项增加类型标记，再用 `union` 保存值。
>
> ```cpp
> enum ValueType { INT_, CHAR_, FLOAT_, LINK_ };
>
> struct TaggedValue {
>  ValueType type;
>  union {
>      int val;
>      char ch;
>      float dir;
>      void* link;
>  } data;
> };
> ```
>
> 这是一种特殊实现。一般线性表仍以同构元素为基本前提。

## 2.2 顺序表

顺序表把线性表中的元素依次存放在一段连续的存储空间中，表项的逻辑顺序与物理顺序一致。因此既可以顺序访问，也可以随机访问。

### 地址计算

若顺序表首地址为 $\alpha$，每个表项占 $l$ 个存储单元，数组下标 $i$ 从 0 开始，则

$$
LOC(i)=
\begin{cases}
\alpha, & i=0,\\
LOC(i-1)+l, & i>0,
\end{cases}
$$

从而

$$
LOC(i)=\alpha+i\cdot l.
$$

地址可以直接由下标计算，所以访问任意已知下标的表项只需 $O(1)$ 时间。

### 顺序表（SeqList）类的定义

`SeqList` 主要包含：

- `data`：动态分配的存储数组；
- `maxSize`：最多可容纳的表项数；
- `last`：最后一个有效表项的数组下标；
- `reSize(newSize)`：改变数组空间大小。

常用接口包括 `Size()`、`Length()`、`Search(x)`、`Locate(i)`、`getData(i, x)`、`Insert(i, x)` 和 `Remove(i, x)`。

> [!warning] 逻辑序号与数组下标不要混用
>
> 第 $i$ 个表项对应 `data[i - 1]`。`Search` 返回的是从 1 开始的表项序号，数组访问使用的却是从 0 开始的下标。

> [!example]- 构造与深复制
>
> ```cpp
> template <class E>
> SeqList<E>::SeqList(int sz) : maxSize(sz), last(-1) {
>  data = new E[maxSize];
> }
>
> template <class E>
> SeqList<E>::SeqList(const SeqList<E>& other)
>  : maxSize(other.maxSize), last(other.last) {
>  data = new E[maxSize];
>  for (int i = 0; i <= last; ++i) {
>      data[i] = other.data[i];
>  }
> }
> ```
>
> 顺序表拥有动态数组时必须复制数组内容。若只复制 `data` 指针，两个对象会共享同一存储区，析构时还可能发生重复释放。

### 顺序查找

顺序查找从表头开始逐项比较。找到时返回逻辑序号，查找失败时返回 0：

```cpp
template <class E>
int SeqList<E>::Search(const E& x) const {
    for (int i = 0; i <= last; ++i) {
        if (data[i] == x) return i + 1;
    }
    return 0;
}
```

设表长为 $n$。若查找每个表项的概率相同，成功查找的平均比较次数为

$$
ACN=\frac{1}{n}\sum_{i=1}^{n}i=\frac{n+1}{2}.
$$

查找失败需要比较 $n$ 次，所以顺序查找的时间复杂度为 $O(n)$。

### 插入

`Insert(i, x)` 把新元素插在第 $i$ 个表项之前，合法范围是 $1\le i\le n+1$。为了避免覆盖数据，必须从后向前移动表项。

> [!example]+ 顺序表插入算法
>
> ```cpp
> template <class E>
> bool SeqList<E>::Insert(int i, const E& x) {
>  if (last == maxSize - 1) return false;  // 表满
>  if (i < 1 || i > last + 2) return false;
>
>  for (int j = last; j >= i - 1; --j) {
>      data[j + 1] = data[j];
>  }
>  data[i - 1] = x;
>  ++last;
>  return true;
> }
> ```

插入前表长为 $n$ 时，在第 $i$ 个位置插入需要移动

$$
n-i+1
$$

个元素。若 $n+1$ 个插入位置等概率出现，平均移动次数为

$$
AMN=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{n}{2}.
$$

### 删除

`Remove(i, x)` 删除第 $i$ 个表项，并通过引用参数 `x` 返回被删元素。合法范围是 $1\le i\le n$，删除后需要从前向后移动后续表项。

> [!example]+ 顺序表删除算法
>
> ```cpp
> template <class E>
> bool SeqList<E>::Remove(int i, E& x) {
>  if (last == -1) return false;           // 表空
>  if (i < 1 || i > last + 1) return false;
>
>  x = data[i - 1];
>  for (int j = i; j <= last; ++j) {
>      data[j - 1] = data[j];
>  }
>  --last;
>  return true;
> }
> ```

删除前表长为 $n$ 时，删除第 $i$ 个表项需要移动 $n-i$ 个元素。若每个删除位置等概率出现，平均移动次数为

$$
AMN=\frac{1}{n}\sum_{i=1}^{n}(n-i)=\frac{n-1}{2}.
$$

> [!important] 插入、删除的代价
>
> 插入和删除的最坏时间复杂度均为 $O(n)$。表头操作移动元素最多；表尾插入和删除不移动已有元素，移动部分为 $O(1)$。

> [!example]- 连续执行插入和删除
>
> 初始状态：
>
> ```text
> data = [12, 25, 31, 48, 60, _, _, _]
> last = 4, maxSize = 8
> ```
>
> 执行 `Insert(3, 40)` 后：
>
> ```text
> data = [12, 25, 40, 31, 48, 60, _, _]
> last = 5
> ```
>
> 移动了 `31、48、60`，共 $n-i+1=3$ 个元素。
>
> 再执行 `Remove(5, x)`，删除当前第 5 个表项 `48`：
>
> ```text
> x = 48
> data = [12, 25, 40, 31, 60, _, _, _]
> last = 4
> ```
>
> 只需将 `60` 前移，共 $n-i=1$ 个元素。

### 顺序表的应用

用顺序表实现集合的“交并”运算

- **并集** `LA = LA \cup LB`：依次取出 `LB` 中的元素；若在 `LA` 中查找失败，则追加到 `LA`；
- **交集** `LA = LA \cap LB`：依次检查 `LA` 中的元素；若在 `LB` 中不存在，则从 `LA` 删除。删除后当前位置变成下一个待检查元素，因此下标不能递增。

若 `LA`、`LB` 已按同一方向有序排列，可以像归并排序一样使用两个游标：

- 求并集时，保留较小元素；相等时只保留一次并同时前进；
- 求交集时，较小元素所在的游标前进；相等时保留该元素并同时前进。

两个表各扫描一次，比较阶段可由反复顺序查找的 $O(mn)$ 降为 $O(m+n)$。

> [!summary]+ 顺序表的特点
>
> - 地址连续，可在 $O(1)$ 时间内随机访问；
> - 不需要为每个表项保存指针，存储密度高；
> - 容量受连续空间限制，扩容需要重新分配和复制；
> - 插入、删除通常需要移动大量元素；
> - 含动态数组的对象需要正确实现深复制和资源释放。

## 2.3 单链表

单链表采用链接存储。每个表项由一个结点表示，结点包含数据域 `data` 和指向直接后继的指针域 `link`：

```text
first -> [a1 | *] -> [a2 | *] -> ... -> [an | NULL]
```

结点在物理存储中不必连续，`first` 保存首元结点的地址。链表可以动态增长，插入和删除不需要整体移动元素，但每个结点需要额外的指针空间。

### 结点与类的定义

```cpp
template <class E>
struct LinkNode {
    E data;
    LinkNode<E>* link;

    LinkNode(const E& value, LinkNode<E>* next = nullptr)
        : data(value), link(next) {}
};
```

### 定位与访问

单链表只能从 `first` 开始沿 `link` 逐个访问结点。访问第 $i$ 个表项需要经过前面的 $i-1$ 个结点，时间复杂度为 $O(n)$，不支持真正的随机访问。

### 不带头结点的插入

在表头插入时需要修改 `first`：

```cpp
newNode->link = first;
first = newNode;
```

已知 `current` 指向插入位置的前驱，在其后插入：

```cpp
newNode->link = current->link;
current->link = newNode;
```

表尾插入使用相同语句，此时 `current->link == nullptr`，新结点自然成为尾结点。

> [!warning] 插入语句的顺序不能交换
>
> 必须先让 `newNode` 保存原后继地址，再修改 `current->link`。若先执行 `current->link = newNode`，原后继结点的地址会丢失；随后再赋值还会使 `newNode->link` 指向自身。

约定 `Insert(i, x)` 是“在第 $i$ 个结点之后插入”，其中 `i=0` 表示插到首元结点之前。这与顺序表“在第 $i$ 个表项之前插入”的接口语义不同。

> [!example]- 单链表完整插入算法
>
> ```cpp
> bool List::Insert(int i, int x) {
>  if (i < 0) return false;
>
>  if (i == 0) {
>      first = new LinkNode<int>(x, first);
>      return true;
>  }
>
>  LinkNode<int>* current = first;
>  int k = 1;
>  while (k < i && current != nullptr) {
>      current = current->link;
>      ++k;
>  }
>  if (current == nullptr) return false;
>
>  current->link = new LinkNode<int>(x, current->link);
>  return true;
> }
> ```

### 不带头结点的删除

删除首元结点时必须单独修改 `first`：

```cpp
LinkNode<int>* del = first;
first = first->link;
delete del;
```

已知 `current` 指向待删结点的前驱时：

```cpp
LinkNode<int>* del = current->link;
current->link = del->link;
delete del;
```

> [!example]- 删除第 i 个表项的完整边界处理
>
> ```cpp
> bool List::Remove(int i, int& x) {
>  if (i < 1 || first == nullptr) return false;
>
>  LinkNode<int>* del = nullptr;
>  if (i == 1) {
>      del = first;
>      first = first->link;
>  } else {
>      LinkNode<int>* current = first;
>      int k = 1;
>      while (k < i - 1 && current != nullptr) {
>          current = current->link;
>          ++k;
>      }
>      if (current == nullptr || current->link == nullptr) {
>          return false;
>      }
>      del = current->link;
>      current->link = del->link;
>  }
>
>  x = del->data;
>  delete del;
>  return true;
> }
> ```

### 带头结点的单链表

头结点位于首元结点之前，本身不保存线性表中的有效数据：

```text
first -> [head | *] -> [a1 | *] -> ... -> [an | NULL]
```

空表时仍保留头结点，只需令 `first->link == nullptr`。把头结点视为第一个数据结点的前驱，表头与表中间的操作便可以统一：

```cpp
// 已知 current 指向插入位置的前驱，current 可以是头结点
newNode->link = current->link;
current->link = newNode;

// 删除 current 的后继，current 可以是头结点
LinkNode<int>* del = current->link;
current->link = del->link;
delete del;
```

> [!important] 头结点的作用
>
> 头结点不是首元结点。设置它的主要目的，是统一空表与非空表、表头与表中间的插入删除操作，减少对 `first` 的特殊修改。

## 2.4 线性链表的其他变形

### 循环链表

循环链表的尾结点不指向 `NULL`，而是重新指向链表前端。因此，只要知道表中任一结点的地址，就可以沿后继方向访问其他结点。

对于带头结点的循环链表：

```text
first -> [head | *] -> [a1 | *] -> ... -> [an | *]
           ^                                  |
           +----------------------------------+
```

- 空表条件：`first->link == first`；
- 扫描结束条件：`current == first`，而不是 `current == nullptr`；
- 若同时保存尾指针 `last`，则 `last->link == first`。

#### 循环链表的搜索

```cpp
template <class E>
CircLinkNode<E>* CircList<E>::Search(const E& x) {
    CircLinkNode<E>* current = first->link;
    while (current != first && current->data != x) {
        current = current->link;
    }
    return current;
}
```

返回 `first` 表示搜索失败；返回其他结点表示成功。其最坏时间复杂度为 $O(n)$。

#### Josephus 问题

Josephus 问题让 $n$ 个人围成一圈，从指定位置开始反复报数，数到第 $m$ 个人时令其出列，再从下一人重新从 1 报数。循环链表可以自然地表示“从尾部回到头部”。

> [!example]- Josephus 的核心循环
>
> 算法维护两个指针：`p` 指向当前报数者，`pre` 指向其前驱。每轮前进 $m-1$ 次后删除 `p`，再从它的后继重新报数：
>
> ```cpp
> for (int i = 0; i < n - 1; ++i) {
> for (int j = 1; j < m; ++j) {
>   pre = p;
>   p = p->link;
> }
> pre->link = p->link;
> delete p;
> p = pre->link;
> }
> ```
>
> 例如从 1 开始、$n=8$、$m=3$ 时，出列顺序为
>
> $$
> 3,6,1,5,2,8,4,
> $$
>
> 最后留下 7。
>
> 若每轮都按 $m$ 次报数逐步移动，时间复杂度为 $O(nm)$；当 $m$ 被视为常数时可写为 $O(n)$。

> [!warning]- `m = 1` 的边界
>
> 上述代码在 `m=1` 时不会进入内层循环，`pre` 可能尚未指向 `p` 的前驱。完整实现应在每轮删除前保证 `pre` 有效，或单独处理 `m=1`。

### 双向链表

双向链表的每个结点同时保存前驱和后继指针：

```text
[lLink | data | rLink]
```

带头结点的双向循环链表中，空表满足

```cpp
first->lLink == first && first->rLink == first
```

任一数据结点 `p` 都应满足：

$$
p=p\to lLink\to rLink=p\to rLink\to lLink.
$$

#### 按方向搜索

假设用参数 `d` 指定搜索方向：`d == 0` 沿前驱方向，`d != 0` 沿后继方向。

```cpp
template <class E>
DblNode<E>* DblList<E>::Search(const E& x, int d) {
    DblNode<E>* current = (d == 0) ? first->lLink : first->rLink;
    while (current != first && current->data != x) {
        current = (d == 0) ? current->lLink : current->rLink;
    }
    return (current == first) ? nullptr : current;
}
```

#### 插入与删除

在 `current` 后插入 `newNode`：

```cpp
newNode->rLink = current->rLink;
current->rLink = newNode;
newNode->rLink->lLink = newNode;
newNode->lLink = current;
```

在 `current` 前插入 `newNode`：

```cpp
newNode->lLink = current->lLink;
current->lLink = newNode;
newNode->lLink->rLink = newNode;
newNode->rLink = current;
```

删除 `current`：

```cpp
current->rLink->lLink = current->lLink;
current->lLink->rLink = current->rLink;
delete current;
```

已知结点时，双向链表插入和删除只修改常数个指针，时间复杂度为 $O(1)$；若需先调用 `Locate` 定位第 $i$ 个结点，总时间复杂度为 $O(n)$。

> [!summary]+ 线性表存储方式对比
>
> | 结构         | 按序号访问 | 已知位置或前驱后的插删 | 扫描终点 |
> | ------------ | ---------: | ---------------------: | -------- |
> | 顺序表       |     $O(1)$ |                 $O(n)$ | `last`   |
> | 单链表       |     $O(n)$ |                 $O(1)$ | `NULL`   |
> | 循环链表     |     $O(n)$ |                 $O(1)$ | 回到表头 |
> | 双向循环链表 |     $O(n)$ |                 $O(1)$ | 回到表头 |

## 2.5 多项式及其运算

$n$ 次多项式可以写为

$$
P_n(x)=a_0+a_1x+a_2x^2+\cdots+a_nx^n
=\sum_{i=0}^{n}a_ix^i,
$$

其中系数为 $a_0,a_1,\ldots,a_n$，指数为 $0,1,\ldots,n$；称为 $n$ 次多项式时应有 $a_n\ne 0$。

表示多项式的方法有很多。

### 第一种：静态系数数组

用数组下标直接表示指数，`coef[i]` 保存 $a_i$。`degree` 记录当前多项式的最高非零指数。

```cpp
class StaticPolynomial {
private:
    static const int maxDegree = 100;
    int degree;
    float coef[maxDegree + 1];

public:
    StaticPolynomial() : degree(0), coef{} {}
};
```

若 $P_n(x)=\sum_{i=0}^{n}a_ix^i$，则可在该类的成员函数内建立如下映射：

```cpp
degree = n;
coef[i] = a_i;  // 0 <= i <= n
```

已知指数 $i$ 时可在 $O(1)$ 时间访问系数，但即使某一项系数为 0，也必须为它保留数组位置。

### 第二种：动态系数数组

最高次数在运行时确定时，可以动态申请 `maxDegree + 1` 个系数位置：

```cpp
#include <algorithm>

class DynamicPolynomial {
private:
    int degree;
    int maxDegree;
    float* coef;

public:
    explicit DynamicPolynomial(int sz)
        : degree(0), maxDegree(sz), coef(new float[sz + 1]{}) {}

    DynamicPolynomial(const DynamicPolynomial& other)
        : degree(other.degree),
          maxDegree(other.maxDegree),
          coef(new float[other.maxDegree + 1]) {
        std::copy(other.coef,
                  other.coef + other.maxDegree + 1,
                  coef);
    }

    DynamicPolynomial& operator=(const DynamicPolynomial& other) {
        if (this == &other) return *this;

        float* replacement = new float[other.maxDegree + 1];
        std::copy(other.coef,
                  other.coef + other.maxDegree + 1,
                  replacement);
        delete[] coef;

        coef = replacement;
        degree = other.degree;
        maxDegree = other.maxDegree;
        return *this;
    }

    ~DynamicPolynomial() {
        delete[] coef;
    }
};
```

动态数组解决了“编译时必须确定最高次数”的问题，却没有解决稀疏浪费：例如

$$
P_{101}(x)=3+5x^{50}-4x^{101}
$$

只有 3 个非零项，仍需分配 102 个系数位置。

> [!warning] 动态数组必须管理复制与释放
>
> 只复制 `coef` 指针会造成浅复制。上面的复制构造函数和赋值运算符都会重新申请并复制整个系数数组；析构函数使用 `delete[]` 释放空间。

### 第三种：非零项数组

稀疏多项式只保存非零项，每项由系数 `coef` 和指数 `exp` 组成，并按指数升序排列：

```cpp
struct ArrayTerm {
    float coef;
    int exp;
};

class TermArrayPolynomial {
private:
    static const int maxTerms = 1000;
    static ArrayTerm termArray[maxTerms];
    static int free;          // 下一空闲位置

    int start;                // 本多项式第一项的位置
    int finish;               // 本多项式最后一项的位置
};

ArrayTerm TermArrayPolynomial::termArray[
    TermArrayPolynomial::maxTerms
];
int TermArrayPolynomial::free = 0;
```

所有多项式对象共享 `termArray`；每个对象用 `[start, finish]` 标记自己的连续区间，`free` 指向下一空闲位置。这种方式把空间开销从“最高指数”降为“非零项数”。

> [!example]- 非零项数组同时存放多个多项式
>
> 可以把多个多项式连续放入共享的 `termArray`，并为每个多项式记录 `start` 和 `finish`，再用 `free` 指向下一空闲位置。
>
> 对
>
> $$
> A(x)=1.8+2.0x^{1000},\qquad
> B(x)=1.2+51.3x^{50}+3.7x^{101},
> $$
>
> | 数组位置 |    0 |    1 |    2 |    3 |    4 |    5 |
> | -------: | ---: | ---: | ---: | ---: | ---: | ---: |
> |   `coef` |  1.8 |  2.0 |  1.2 | 51.3 |  3.7 | 空闲 |
> |    `exp` |    0 | 1000 |    0 |   50 |  101 |    - |
>
> 此时 `A.start = 0`、`A.finish = 1`，`B.start = 2`、`B.finish = 4`，`free = 5`。
>
> 共享数组只需保存 5 个非零项，而系数数组必须一直开到最高指数 1000。

### 第四种：链表存储表示

链表只保存非零项。每个结点的数据域由系数和指数构成：

```cpp
#include <iostream>

struct Term {
    float coef;
    int exp;
    Term* link;

    Term(float c, int e, Term* next = nullptr)
        : coef(c), exp(e), link(next) {}

    Term* InsertAfter(float c, int e);
    friend std::ostream& operator<<(std::ostream&, const Term&);
};

Term* Term::InsertAfter(float c, int e) {
    link = new Term(c, e, link);
    return link;
}
```

`InsertAfter` 在当前结点之后建立新项，并返回新结点地址。归并相加时可用返回值同步更新结果链尾 `pc`。

> [!example]- 链式多项式的完整类骨架
>
> ```cpp
> class LinkedPolynomial {
> public:
>  LinkedPolynomial() : first(new Term(0, -1)) {}
>
>  LinkedPolynomial(const LinkedPolynomial& other)
>      : LinkedPolynomial() {
>      copyFrom(other);
>  }
>
>  LinkedPolynomial& operator=(const LinkedPolynomial& other) {
>      if (this != &other) {
>          clear();
>          copyFrom(other);
>      }
>      return *this;
>  }
>
>  ~LinkedPolynomial() {
>      clear();
>      delete first;
>  }
>
>  int maxOrder() const {
>      int order = -1;
>      for (const Term* p = first->link;
>           p != nullptr;
>           p = p->link) {
>          order = p->exp;
>      }
>      return order;
>  }
>
> private:
>  Term* first;  // 指向指数为 -1 的头结点
>
>  void clear() {
>      Term* p = first->link;
>      while (p != nullptr) {
>          Term* next = p->link;
>          delete p;
>          p = next;
>      }
>      first->link = nullptr;
>  }
>
>  void copyFrom(const LinkedPolynomial& other) {
>      Term* tail = first;
>      for (const Term* p = other.first->link;
>           p != nullptr;
>           p = p->link) {
>          tail = tail->InsertAfter(p->coef, p->exp);
>      }
>  }
>
>  friend std::ostream& operator<<(
>      std::ostream&, const LinkedPolynomial&
>  );
>  friend std::istream& operator>>(
>      std::istream&, LinkedPolynomial&
>  );
>  friend void Add(
>      const LinkedPolynomial&,
>      const LinkedPolynomial&,
>      LinkedPolynomial&
>  );
>  friend void Mul(
>      const LinkedPolynomial&,
>      const LinkedPolynomial&,
>      LinkedPolynomial&
>  );
> };
> ```

通常设置头结点，并使各项按指数升序排列。以

$$
A(x)=1-10x^6+2x^8+7x^{14}
$$

为例，链表为

```text
head -> (1, 0) -> (-10, 6) -> (2, 8) -> (7, 14) -> NULL
```

> [!note] 为什么链表更适合动态多项式
>
> 多项式运算会使非零项数不断变化。链表能够按需申请结点，插入、删除不必移动其他项，也便于同时处理多个多项式；代价是额外的指针空间。

### 有序链表的多项式相加

设两个多项式分别按指数升序存储在带头结点的单链表中，`pa`、`pb` 指向当前待处理项，`pc` 指向结果链表 `C` 的最后一个结点。

1. 若 `pa->exp < pb->exp`，把 `pa` 指向的项加入 `C`，`pa` 前进；
2. 若 `pa->exp > pb->exp`，把 `pb` 指向的项加入 `C`，`pb` 前进；
3. 若指数相等，系数相加；和不为 0 时建立结果结点，然后 `pa`、`pb` 同时前进；
4. 一个链表结束后，把另一个链表的剩余项接到 `C` 后。

> [!example]- 多项式链表相加的完整代码
>
> ```cpp
> void Add(const LinkedPolynomial& A,
>       const LinkedPolynomial& B,
>       LinkedPolynomial& C) {
>  C.clear();
>
>  const Term* pa = A.first->link;
>  const Term* pb = B.first->link;
>  Term* pc = C.first;
>
>  while (pa != nullptr && pb != nullptr) {
>      if (pa->exp < pb->exp) {
>          pc = pc->InsertAfter(pa->coef, pa->exp);
>          pa = pa->link;
>      } else if (pa->exp > pb->exp) {
>          pc = pc->InsertAfter(pb->coef, pb->exp);
>          pb = pb->link;
>      } else {
>          float sum = pa->coef + pb->coef;
>          if (sum != 0) {
>              pc = pc->InsertAfter(sum, pa->exp);
>          }
>          pa = pa->link;
>          pb = pb->link;
>      }
>  }
>
>  while (pa != nullptr) {
>      pc = pc->InsertAfter(pa->coef, pa->exp);
>      pa = pa->link;
>  }
>  while (pb != nullptr) {
>      pc = pc->InsertAfter(pb->coef, pb->exp);
>      pb = pb->link;
>  }
> }
> ```

> [!warning] 多项式归并相加的前提
>
> 两个输入链表必须按指数采用同一方向有序排列。零系数项不应保留在结果中，否则表示不再规范。上述实现会先清空 `C`，所以要求结果对象 `C` 与输入对象 `A`、`B` 不是同一个对象。

> [!example]- 合并同类项并删除零系数项
> $$
> \begin{aligned}
> A(x)&=1-3x^6+7x^{12},\\
> B(x)&=-x^4+3x^6-9x^{10}+8x^{14}.
> \end{aligned}
> $$
>
> | `pa` 当前项 | `pb` 当前项 | 处理                 | 结果链表新增项 |
> | ----------- | ----------- | -------------------- | -------------- |
> | $(1,0)$     | $(-1,4)$    | $0<4$，取 `pa`       | $1$            |
> | $(-3,6)$    | $(-1,4)$    | $4<6$，取 `pb`       | $-x^4$         |
> | $(-3,6)$    | $(3,6)$     | 指数相等，系数和为 0 | 不建结点       |
> | $(7,12)$    | $(-9,10)$   | $10<12$，取 `pb`     | $-9x^{10}$     |
> | $(7,12)$    | $(8,14)$    | $12<14$，取 `pa`     | $7x^{12}$      |
> | `NULL`      | $(8,14)$    | 接入 `pb` 的剩余项   | $8x^{14}$      |
>
> 因此
>
> $$
> A(x)+B(x)=1-x^4-9x^{10}+7x^{12}+8x^{14}.
> $$

若两个多项式分别有 $m$ 项和 $n$ 项，每个结点最多扫描一次，因此相加算法的时间复杂度为 $O(m+n)$。若结果链表新建结点，额外空间复杂度为 $O(m+n)$；若复用原结点，额外辅助空间可以降为 $O(1)$。

## 2.6 静态链表

静态链表用数组模拟链表。每个数组元素包含数据域 `data` 和链接域 `link`，其中 `link` 保存下一结点的数组下标，而不是内存地址。

课件示例的物理存储为：

| 数组下标 | 0    | 1     | 2     | 3     | 4          | 5     |
| -------: | ---- | ----- | ----- | ----- | ---------- | ----- |
|   `data` | -    | $a_3$ | $a_4$ | $a_1$ | $a_5$      | $a_2$ |
|   `link` | 3    | 2     | 4     | 5     | -1（或 0） | 1     |

0 号元素是表头结点，沿下标链接得到

```text
0 -> 3(a1) -> 5(a2) -> 1(a3) -> 2(a4) -> 4(a5)
```

- 非循环静态链表的尾结点令 `link = -1`；
- 循环静态链表的尾结点令 `link = 0`，重新回到表头；
- 改变逻辑顺序只需修改 `link`，不必移动元素的物理位置；
- 因为底层仍是数组，整个运算过程中总容量固定。

> [!summary]+ 顺序表、动态链表与静态链表
>
> | 特性         | 顺序表       | 动态链表 | 静态链表                                   |
> | ------------ | ------------ | -------- | ------------------------------------------ |
> | 物理空间     | 连续         | 可分散   | 连续数组                                   |
> | 关系表示     | 相邻位置     | 地址指针 | 整数下标                                   |
> | 容量         | 固定或扩容   | 动态申请 | 固定                                       |
> | 改变逻辑顺序 | 通常移动元素 | 修改指针 | 修改下标链接                               |
> | 随机访问     | 支持         | 不支持   | 底层数组可下标访问，但逻辑定位仍需沿链扫描 |
